# 동해 노래 만들기

동해 표기와 관련한 여러 관점을 살펴보고, 학습 내용을 직접 가사와 앨범 커버로 표현하는 교육용 웹사이트입니다.

학생은 네 가지 주제 가운데 하나를 골라 학습 내용을 정리한 뒤, Gemini에서 가사와 앨범 커버를 만들고 Suno에서 노래를 제작합니다. 마지막에는 Padlet에 결과물을 공유하고 서로의 작품을 감상할 수 있습니다.

학습은 `동해 표기 논쟁 학습하기 → 노래 주제 정리하기 → 가사 프롬프트 확인하기 → Suno로 노래 제작하기 → 앨범 커버 프롬프트 확인하기 → 결과물 공유하기` 순서로 진행됩니다. 입력한 학습 내용은 현재 브라우저에 저장되며, 외부 생성형 AI와 공유 게시판은 각 서비스에서 열립니다.
